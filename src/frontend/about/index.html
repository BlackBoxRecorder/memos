核心体验

瀑布流首页

采用 Masonry 瀑布流布局，浏览备忘录如同翻阅杂志。内置虚拟滚动技术，即使上千条记录也能流畅滚动。

  • ▸ Tag 标签筛选 — 点击标签即时过滤，快速定位目标内容
  • ▸ 相似搜索 — 基于文本嵌入的语义搜索，发现关联 memo
  • ▸ Markdown 渲染 — 支持完整 Markdown 语法，内容呈现清晰美观
  • ▸ 深色 / 浅色主题 — 一键切换，适配不同阅读环境
内容管理

管理后台

独立的密钥认证管理后台，提供完整的备忘录生命周期管理。从创建到归档，一切尽在掌控。

  • ▸ 完整 CRUD — 新建、编辑、删除备忘录，支持可见性切换与置顶
  • ▸ 左侧时间线 — 按时间轴快速跳转，回顾任意时刻的记录
  • ▸ AI 工具箱辅助 — 创建时一键调用 AI 润色、扩写、总结
  • ▸ Tag 自动建议 — 输入标签时智能补全，保持分类一致
AI 创作

创意生成 & 提示词管理

内置 AI 创意工作台，支持多种生成模式。自定义提示词库，让 AI 按你的方式写作。

  • ▸ 创意生成 — 给定主题，AI 生成创意内容或灵感拓展
  • ▸ 内容聚合 — 多段素材汇整为连贯短文
  • ▸ 日记优化 — 润色日常记录，提升表达清晰度
  • ▸ 知识整理 — 将零散笔记组织为结构化知识
  • ▸ 自定义提示词 — 管理个人提示词库，精细控制生成行为
灵活配置

多模型自由选择

不绑定单一 AI 服务商。支持配置多个模型提供商，按需切换，灵活控制成本和效果。

  • ▸ 多提供商支持 — 兼容主流 AI 服务 API
  • ▸ 可视化配置 — 在界面中直接选择和切换模型
  • ▸ 即切即用 — 切换模型无需重启，即时生效
数据自由

数据导入导出

你的数据属于你。支持从 Flomo 等平台迁移数据，也可随时导出为 JSON 格式。

  • ▸ Flomo HTML 导入 — 解析 Flomo 导出的 HTML 文件，一键迁移全部记录
  • ▸ JSON 导出 — 完整导出备忘录数据，格式开放便于二次利用
  • ▸ 无锁定风险 — 数据始终可自由迁移，不被平台绑定
