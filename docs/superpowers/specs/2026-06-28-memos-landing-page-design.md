# Memos 产品落地页设计

## 概述

为 Memos 备忘录系统构建一个中文化的产品落地页，面向潜在用户和现有用户，展示产品功能亮点和使用场景。页面为纯单文件 HTML，通过 CDN 引入 Tailwind CSS，深色主题，与产品截图色调协调。

## 页面目标

混合型落地页 — 既有产品介绍吸引新用户，也有功能概览供现有用户参考。

## 设计风格

- **基调**：简洁现代风，大量留白，聚焦内容
- **配色**：深色背景（`#0d1117` ~ `#161b22`），GitHub 暗色系，与产品截图协调
- **主色**：青蓝 `#58a6ff` 用于强调和 CTA
- **卡片底色**：`#1c2128` 稍亮于背景
- **文字层级**：主文字 `#f0f6fc` / 次要 `#8b949e` / 辅助 `#484f58`
- **字体**：系统字体栈

## 技术方案

- **方案**：纯单文件 HTML + Tailwind CSS CDN
- **样式**：Tailwind 原子类为主，少量 `<style>` 块做深色主题定制
- **交互**：截图区横向轮播（手写少量 vanilla JS）
- **依赖**：零外部依赖，浏览器直接打开即可查看

## 内容架构

### Hero 区

- 产品名 "Memos" + 一句核心定位语
- 副标题简述核心价值
- CTA 按钮（跳转到应用首页）

### 功能亮点区（5 大板块，图文交错 + 截图轮播）

每个板块布局规则：
- 奇数板块：文字居左，截图轮播居右
- 偶数板块：截图轮播居左，文字居右
- 每个板块默认 **3 个截图槽位**，不足 3 张的空槽隐藏；板块 3 有 4 张图，使用 4 个槽位
- 截图区为横向滚动容器，支持拖拽 / 触控滑动 / 左右箭头
- 底部圆点指示器显示当前位置

#### 板块 1：瀑布流首页（memo1, memo2, memo3）

- **功能点**：Masonry 瀑布流布局、虚拟滚动、tag 标签筛选、相似搜索与相似 memo 查看、Markdown 内容渲染、深色/浅色主题切换
- **截图**：3 张

#### 板块 2：管理后台（memo12, memo13, memo14）

- **功能点**：备忘录 CRUD 操作、可见性切换、二次确认删除、内容编辑、置顶功能、左侧时间线跳转、备忘录创建时调用 AI 工具箱辅助、tag 标签自动建议、Markdown 渲染预览
- **截图**：3 张

#### 板块 3：Creative 创意生成 + Prompt 提示词管理（memo7, memo8, memo9, memo10）

- **功能点**：创意内容生成、内容聚合、日记优化、知识整理等 AI 能力、自定义提示词管理
- **截图**：4 张（超过 3 个槽位时用 4 张）

#### 板块 4：多模型选择（memo5, memo6）

- **功能点**：支持配置选择不同提供商的 AI 大模型
- **截图**：3 张（其中 1 个槽位留空待补充图片）

#### 板块 5：数据导入导出（memo11）

- **功能点**：Flomo HTML 数据导入、JSON 格式导出，方便数据迁移
- **截图**：3 张（其中 2 个槽位留空待补充图片）

### 使用场景区

3 张场景卡片横向排列：
- 个人日记 — 随时记录生活点滴
- 知识管理 — 整理学习笔记和资料
- 灵感捕捉 — 快速抓住一闪而过的创意

### 页脚

- 项目信息简述
- 技术栈标识（Bun + SQLite + Hono + VanJS）
- 链接（GitHub 等）

## 截图轮播交互

- 横向滚动容器，`overflow-x: auto`，`scroll-snap-type: x mandatory`
- 每张截图 `scroll-snap-align: start`，宽度占满轮播可视区
- 支持鼠标拖拽滚动和触控滑动
- 左右箭头按钮（可选，hover 区域时显示）
- 底部圆点指示器，点击可跳转到对应截图
- 自动播放不作要求
