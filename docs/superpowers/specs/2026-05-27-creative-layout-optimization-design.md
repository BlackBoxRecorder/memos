# Creative 页面顶部布局优化设计

## 背景

Creative 页面的 GenerateBar 当前将标签列表和提示词选择器放在同一行（flex 布局），导致标签不满一行时右侧留白，提示词选择器被推到最远端。同时 PromptDrawer 侧边抽屉视觉偏重（360px 宽、实色背景、重阴影）。

## 目标

1. 消除标签区域的无效留白
2. 让提示词选择器位置更合理
3. 让提示词管理抽屉视觉上更轻量

## 改动范围

仅涉及 2 个前端文件，无 API / state / 数据模型改动。

---

## Task 1: GenerateBar 布局重构

**文件**: `src/frontend/admin/components/GenerateBar.ts`

### 当前结构

```
┌──────────────────────────────────────────┐
│ [标签1] [标签2] ... [标签N]   [下拉] [⚙] │  ← 同一行 flex
├──────────────────────────────────────────┤
│ [textarea......................] [生成]   │
└──────────────────────────────────────────┘
```

### 目标结构

```
┌──────────────────────────────────────────┐
│ [下拉选择提示词] [⚙]                      │  ← 提示词行，紧凑左对齐
├──────────────────────────────────────────┤
│ [标签1] [标签2] [标签3] ... [标签N]       │  ← 标签行，独占整行
├──────────────────────────────────────────┤
│ [textarea......................] [生成]   │  ← 输入行，不变
└──────────────────────────────────────────┘
```

### 具体改动

1. `GenerateBar()` 内的 top row div 拆成两个独立 div：
   - 第一个 div：`PromptSelector()`，左对齐紧凑排列
   - 第二个 div：`TagSelector()`，独占整行
2. `PromptSelector` 移除 `flex-shrink:0`，改为简单左对齐
3. `TagSelector` 移除 `flex:1;min-width:0`，直接使用 `display:flex;flex-wrap:wrap;gap:6px`

## Task 2: PromptDrawer 视觉轻量化

**文件**: `src/frontend/admin/components/PromptDrawer.ts`

### 优化项

| 属性 | 当前值 | 目标值 |
|------|--------|--------|
| 宽度 | `360px` / `max-width:90vw` | `300px` / `max-width:80vw` |
| 阴影 | `box-shadow:-4px 0 20px rgba(0,0,0,0.1)` | `box-shadow:-2px 0 12px rgba(0,0,0,0.06)` |
| 圆角 | 无 | `border-radius:12px 0 0 12px` |
| 动画 | `slideInRight 0.2s` | `slideInRight 0.15s` |

### 内容结构

不变：标题、新建按钮、提示词列表、编辑/删除操作全部保留。
